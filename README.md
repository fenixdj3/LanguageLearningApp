# LanguageLearningApp

**LanguageLearningApp** — мобильное приложение для изучения языков на базе **React Native + Expo**.

Сейчас в проекте уже есть:
- регистрация и вход пользователей;
- словарь с категориями;
- экран обучения (карточки/практика);
- настройки приложения;
- Firebase-аутентификация;
- локальная работа с данными (SQLite).

---

## Как скачать проект

### Вариант 1 (через Git)
```bash
git clone <URL_ЭТОГО_РЕПОЗИТОРИЯ>
cd LanguageLearningApp
```

### Вариант 2 (через ZIP)
1. Откройте страницу репозитория в браузере.
2. Нажмите **Code** → **Download ZIP**.
3. Распакуйте архив.
4. Откройте папку проекта в терминале.

## Требования

Перед запуском установите:
- **Node.js 18 LTS** (или совместимую версию);
- **npm** (обычно ставится вместе с Node.js);
- приложение **Expo Go** на телефон (Android/iOS), если хотите запускать на реальном устройстве.

Проверка версий:
```bash
node -v
npm -v
```

---

## Установка зависимостей

В корне проекта выполните:
```bash
npm install
```

## Как запустить проект сейчас

### Базовый запуск
```bash

```

После запуска откроется Expo DevTools/QR-код.

```bash
npm run android
```

### Запуск на iOS-симуляторе (только macOS)
```bash

```

```bash

```

## Важное по Firebase

В проекте уже зашита конфигурация Firebase в `src/services/firebase.js`.

Для production лучше:
- вынести конфигурацию в переменные окружения;
- разделить окружения (`dev` / `prod`);
- ограничить ключи и домены в консоли Firebase.

## Что можно улучшить в проекте

Ниже — практичный список улучшений в порядке приоритета.

### 1) Безопасность и конфигурация
- Убрать чувствительные конфиги из исходников (Firebase и прочее).
- Добавить `.env.example` и загрузку env-переменных.
- Явно настроить правила безопасности Firebase (Auth/Storage/Firestore, если используется).

### 2) Качество кода
- Подключить **ESLint + Prettier** и добавить скрипты `lint`, `format`.
- Добавить **TypeScript** (или хотя бы JSDoc-типизацию) для устойчивости к ошибкам.
- Разбить крупные экраны на более мелкие переиспользуемые компоненты.

### 3) Архитектура и состояние
- Упорядочить слои: `screens` / `features` / `shared` / `services`.
- Централизовать работу с состоянием (Context + reducer / Zustand / Redux Toolkit).
- Выделить единый слой доступа к данным (SQLite/Firebase репозитории).

### 4) UX и продукт
- Добавить онбординг и подсказки для первого запуска.
- Улучшить флоу обучения: интервальные повторения, статистика, прогресс по темам.
- Сделать офлайн-first сценарии и индикаторы синхронизации.

### 5) Тестирование и CI
- Добавить юнит-тесты (Jest + React Native Testing Library).
- Добавить smoke/e2e (Detox или Maestro).
- Настроить CI (например, GitHub Actions): `install → lint → test`.

### 6) Производительность
- Проверить лишние ререндеры экранов и оптимизировать тяжёлые списки.
- Добавить lazy-loading для неключевых ресурсов.
- Провести ревизию пакетов и удалить неиспользуемые зависимости.

---

3. Настроить CI-проверки.
4. После этого — улучшать функциональность обучения и аналитику прогресса.
